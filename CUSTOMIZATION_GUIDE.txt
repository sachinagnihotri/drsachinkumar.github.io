9. PUBLICATIONS (publications.html)
================================================================================

LOCATION: Throughout file, organized by year

FORMAT FOR EACH PUBLICATION:
    <div class="publication">
        <div class="pub-title">1. Paper Title Here</div>
        <div class="pub-authors">Author, Author, Author</div>
        <div class="pub-info">Journal/Conference Name, Year</div>
        <div class="pub-link"><a href="PASTE_DOI_URL" target="_blank">DOI: link</a></div>
    </div>

TO ADD PUBLICATION:
1. Find the year section where publication belongs
2. Copy entire <div class="publication">...</div> block
3. Update title, authors, journal/conference, and DOI
4. Place in chronological order within that year (newest first)
5. Update the number in <div class="pub-title"> (1, 2, 3, etc.)

TO REMOVE PUBLICATION:
Delete entire <div class="publication">...</div> block

13. COLOR CUSTOMIZATION
================================================================================

PRIMARY BLUE (used for headings, links, accents):
Current: #0066cc
Location: Multiple <style> sections, search for "0066cc"
Change: Replace all #0066cc with your preferred color hex code

EXAMPLES OF COLORS:
- Dark Blue: #003366
- Professional Green: #0d6438
- Academic Red: #8b1a1a
- Modern Gray: #2c3e50

TO CHANGE COLOR:
1. Open each HTML file
2. Find <style> section near top
3. Search for #0066cc
4. Replace with your color code
5. Repeat for all files (or some might inherit from main)

NEED HELP?
================================================================================

COMMON ISSUES:

Q: Site not showing?
A: Wait 5 minutes, then refresh browser and clear cache

Q: Image not showing?
A: Make sure file is named exactly "profile.png"

Q: Links broken?
A: Use full URLs starting with https://

Q: Formatting looks wrong?
A: Check browser developer tools (F12) for errors

Q: Can't find section to edit?
A: Use Ctrl+F to search for specific text
